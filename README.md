# VSTEP Practice Test 3 · Reading · Teacher

Trang GitHub Pages luyện tập; giao diện và chức năng dùng lại từ Practice Test 2. Nội dung và đáp án lấy từ `data(2).js` người dùng cung cấp, các file audio `Q...(2).mp3` là tài liệu TEST 3.

## Triển khai

1. Giải nén ZIP và tải **toàn bộ file cùng cấp** (không thư mục con) lên root của repository.
2. Settings → Pages → Deploy from a branch → `main` → `/(root)`.
3. Truy cập `index.html` qua GitHub Pages.

- Listening: 35 câu/14 audio MP3 theo cấu trúc Part 1 (8), Part 2 (12), Part 3 (15).
- Reading: 4 passages/40 câu; không có Warm-up hoặc Paraphrase.
- Teacher: mỗi câu có các nút Key, Evidence, Explain riêng. Learner: Check chỉ cho biết đúng/sai.
- Giữ nguyên nội dung, phương án và Key của tài liệu nguồn. Đối chiếu lại những nghi vấn ở tài liệu nguồn trước khi sử dụng làm bài thi có tính chính thức.
- GitHub Pages công khai không bảo mật được Key ẩn trong JavaScript.

## Kiểm tra nguồn

- Q1 Listening: nguồn script dùng mã chuyến bay EB380, cần tự nghe lại file gốc để xác thực tên chuyến bay.
- Q31 Listening: nguồn có các con số về tỷ lệ béo phì, cần đối chiếu câu hỏi và bài nói nếu dùng để đánh giá chính thức.
- Listening Part 3, Q26–30: hướng dẫn trong nguồn ghi nhầm `21–25` dù nội dung là 26–30; giao diện đã hiển thị nhãn 26–30.
